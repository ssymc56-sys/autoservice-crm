# АвтоПост

Календарь дневной записи и табель механиков для владельца автосервиса. При первом открытии появятся вымышленные механики, семь дней смен и примеры визитов.

## Как открыть на компьютере

Откройте файл `index.html` в Chrome или Firefox. Держите его в одной папке с файлами `styles.css` и `app.js`. Если браузер ограничивает сохранение для локальных файлов, используйте запуск через Python ниже.

## Как запустить через Python

Из папки проекта выполните `python3 -m http.server 4173 --bind 127.0.0.1`, затем откройте в браузере `http://localhost:4173`. Устанавливать библиотеки не нужно.

Записи и смены сохраняются в браузере. На другом устройстве, в другом профиле или по другому адресу будет свой набор данных. Используйте только вымышленные данные.
